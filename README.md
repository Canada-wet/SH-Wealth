# Together Wealth

伴侣共同维护的家庭财富工作台：资产与负债、成员贡献、每月现金流、目标与规划、完整历史，以及可修改数据的浮动财富顾问。

v0.2.0 新增[市场与家庭联动、每日决策心理学及管理员版本记录](docs/market-wealth-learning.md)。市场页按已确认的账户配置比例关联证券，不把自选或行情直接写成资产收益；`/learn` 支持个人收藏、回看与单独订阅每日提醒，`/updates` 供两位授权管理员查看。部署先执行 `supabase/learning.sql`；个人收藏与提醒偏好独立存于 Supabase，不在共同账本 JSON 备份中。

## 运行与验证

```bash
npm install
npm run dev
npm test
npm run build
```

浏览器交互测试使用独立的生产构建，不会污染开发缓存：

```bash
npx playwright install chromium
NEXT_DIST_DIR=.next-test npm run build
npm run test:e2e
```

CI 浏览器测试使用隔离的假身份服务，不接触真实账号。离线复现：

```bash
NEXT_DIST_DIR=.next-test NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:3102 NEXT_PUBLIC_SUPABASE_ANON_KEY=offline-test-anon-key npm run build
E2E_USE_MOCK_AUTH=1 npm run test:e2e
```

开发缓存在 `.next-dev`，生产缓存在 `.next`，测试缓存在 `.next-test`。修改环境变量或 `next.config.ts` 后需要重启开发服务。

新增的十项日常体验优化（语音、确认、草稿、复盘、假设测算）：[功能说明](docs/experience-improvements.md)。自动模式日常优先 DeepSeek，复杂规划使用 GPT‑6；具体模型可通过服务端环境变量覆盖。

自然语音：点击顾问内“开始对话”，无需选择语种；说完停顿约 1.2 秒自动提问，回复自动播报并继续听。口语回复简短，完整分析仍随聊天保存；修改数据暂停等待页面确认。语音和文字分析分开路由、计费。详见 [自然语音说明](docs/natural-voice.md)。

新增 [十项共同维护体验](docs/household-workspace.md)：批量估值表、账户资料、逐项过期检查、安全撤销、历史差异、目标储蓄节奏、共同开支分摊、负债成本、隐私遮挡和编辑保护。金额继续从同一资产、收支与目标记录计算，不添加孤立账本。

## 数据保存与共享

数据统一保存在 `together-wealth-v3`，包含数值资产、可空本年回报、负债、贡献、现金流、成员、目标、规划、每次财务变动的完整快照、对话和模型偏好。写入成功后界面才显示已保存；浏览器容量不足或数据损坏会明确报错。上一版本保存为恢复备份，支持完整 JSON 导入导出。旧版本的存储自动迁移，删空的账户不会重新生成示例数据。旧版缺少准确日期的历史仍可查看与导出，不生成虚构时间戳。

本机保存只属于当前浏览器和网站地址：`localhost` 与 Vercel 不共享本地存储，部署代码不会上传浏览器中的财富数据。登录后应用自动连接两位成员的同一个 Supabase 家庭空间；新设备自动加载云端数据，后续修改自动同步。

Supabase 配置：

1. 将 `.env.example` 的配置放入 `.env.local` 或 `.env`。这些文件已加入 Git 忽略规则。
2. 新项目先运行 `supabase/schema.sql`，再依次执行 `supabase/persistence.sql`、`supabase/push.sql`、`supabase/access.sql`、`supabase/shared-home.sql`、`supabase/channels.sql`、`supabase/voice.sql`。
3. 由管理员预先创建并确认两个授权账号，页面不开放注册。登录时自动创建或复用唯一家庭，并关联两位成员，不需要手动分享邀请代码。
4. 后续保存自动同步；重新打开恢复已登录的家庭连接。实时事件、窗口恢复可见和轮询一起同步伴侣的更新。

云端写入通过带版本校验的 RPC 执行。两个设备同时修改时会拒绝旧版本覆盖，而不是静默丢失数据。RLS 限制家庭数据读取，云端保留完整文档修改历史。如果本机和云端都已有不同的财务记录，自动同步暂停，由用户比较并决定保留哪份；损坏的本机记录不会作为空文档上传。首次迁移前的本机数据另存私密浏览器备份，可在“备份与家庭同步”导出。

## 统一的计算规则

- 净资产 = 总资产 − 总负债；主目标进度使用净资产。
- 类别与成员持有占比都按实际账户金额 / 总资产计算；自定义类别会单独显示。
- 贡献按真实投入与取出记录。关联账户的投入增加估值，取出减少估值；编辑只应用差额，删除撤回对应变动。独立历史出资不改变已录入估值，避免重复计入。
- 贡献占比使用累计投入金额；净贡献另外显示，和资产持有归属分开。
- 现金流使用每月税后收入与开支；必要开支自动用于应急金目标。现金资产同步到规划的当前应急金参考值。
- 本年回报为用户记录的百分比，可以是负数、零或留空，不自动推算回报，也不改变账户估值。

## 市场看板

市场工作台支持固定区块导航与当前位置高亮、独立速览搜索、紧凑 / 舒适密度及本机偏好恢复；隐私与行情口径按需展开。搜索少量标的时保持卡片尺寸，手机操作热区与键盘焦点优化，不改动家庭账本。

新增置顶「自选涨跌速览」：以报价卡片集中查看每只自选的最新价格、日涨跌额和涨跌幅；按全部 / 美股 / 加拿大筛选，点击代码打开本站图表。沿用同一份可共享自选，管理区搜索不缩减速览。卡片按需加载，支持单项重试、来源核对及 ZGIN 缺报价提示；遵循原有外部行情开关，不改家庭资产。

市场页每日简报：情绪（VIX / VIX3M）、经济前瞻（初请失业金 / 住宅许可）、AI 产业代理（电子产品新订单 / 半导体及元件产出和产能利用率）。DeepSeek 优先、每日共享生成与归档、最近 7 份可回看；模型失败明确标记规则摘要，保留数值、统计期间和原始来源。每日 UTC 14 点定时运行，首次打开可补齐；只发送固定公开序列，不发送家庭账本或聊天。部署前运行 `supabase/market-briefings.sql`；沿用现有 CRON_SECRET 和 Supabase 服务端凭证，无新增行情订阅。

功能闭环修复：点证券后可就地授权加载，跨域窗口提供状态、重载和替代入口；自选可编辑、删除撤销，过期编辑拒绝覆盖；官方快照可下载，并在浏览器允许时缓存以便离线重开，部分数据源故障保留旧观测与原日期。已有登录自动返回目标页，显式重新登录保留表单，市场页可退出当前设备。外部行情受覆盖与授权限制，不把窗口载入当作报价成功。

独立 `/markets` 页面保留左侧主导航和当前页高亮，返回资产等家庭区块自动定位。涨跌速览支持研究主题交叉筛选；投资研究工作台记录逐只标的的逻辑、风险、失效条件与复盘日期，随私密家庭文档同步。加币压力试算区分 CAD 报价与外币收益，不重复叠加汇率，不改账本。宏观研究保留通胀双线、非农三月均值、6 / 12 / 24 期窗口、美债同日曲线与历史比较、两组期限利差、精确单位及观测值表。缺月不补数，不伪造一致预期、经济评分或实际仓位。

首页新增市场入口：CAD 对人民币 / 美元 / 日元的盘中参考与央行日均、30 项可编辑共享自选、延迟股票 / ETF 报价和历史图表、六个期限美债收益率、CPI / 核心 CPI / GDP / 非农 / 失业率。源日期、统计口径和延迟分开说明；行情不自动改资产估值。外部行情须主动启用，不上传家庭金额或聊天。SPCX 已确认为 SpaceX；ZGIN 暂无行情源报价，提供官方核对链接。详见 [市场看板说明](docs/market-dashboard.md)。

## 财富顾问

实时信息可通过顾问中的“联网搜索”查证，沿用现有 OpenAI key，回答仍按 DeepSeek 优先路由。来源链接与检索时间会随聊天保存；只发送公共金融主题，不上传家庭账本，联网回答不执行数据操作。详见 [联网查证说明](docs/web-search.md)。

支持 OpenAI 快速 / 均衡 / 深度、Anthropic 快速 / 深度、DeepSeek 快速 / 深度。自动路由按问题复杂度和已配置的 provider 选择；模型 ID 可通过环境变量替换。模型和路由原因显示在回复中。

顾问读取当前资产、负债、贡献、现金流、成员、目标、规划及近期对话；明确的数据修改请求通过校验后先展示前后差异，用户确认后一次性保存。支持资产回报、负债、贡献、现金流、目标与规划修改；项目重名、数据过期或无效金额会拒绝执行。假设题与分析问题不执行数据变更。

没有配置外部模型时使用明确标注的本地数据助手，可查询数据及执行基础账户修改。外部模型失败不会显示伪造的成功；聊天内容和模型偏好会保存。

顾问支持新建对话、搜索历史、回看与继续提问；新建不会删除旧聊天。完整对话随家庭文档同步和备份，旧版单线程聊天自动兼容，缺失的日期不伪造。阅读位置按设备保存，回看历史不会切换伴侣的聊天页面。模型只收到所选对话的有界上下文，保留开头与最近消息；当前财务数据仍来自最新家庭记录。

当前模型配置参考：[OpenAI](https://developers.openai.com/api/docs/guides/latest-model)、[Anthropic](https://platform.claude.com/docs/en/models/overview)、[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)。

## 主动提醒与 Web Push

首页以净资产、账面月结余、现金缓冲参考和不计收益的目标基线串联总览与明细。点击成员占比可筛选对应资产；点击现金缓冲可展开应急金计划。收支未补齐时不把缺失项当成零，现金覆盖只按现金类别汇总，仍需核对 GIC 等账户的可动用程度。目标基线按剩余日历月（含本月）至目标年末平摊差额，不是投资收益预测。

即时主动洞察来自同一份家庭记录：收支缺口、应急金目标、财务快照时效、目标节奏、类别结构与成员贡献。首页只突出一个下一步，顾问气泡显示待讨论数量，聊天内可展开更多事项。一键准备讨论不会直接修改账目。标记已处理会同步保存，本月不再反复提示相同事项；下月可重新复盘。手机不弹出遮挡内容的浮动建议。

每周 Vercel Cron 先持久化规则复盘，再使用自动路由的快速档生成简短 AI 周报，来源与模型明确标记。按家庭和周去重，重复执行不反复调用模型；模型失败或未配置时保留明确标注的规则复盘。模型只收到汇总数据与观察事项，不发送历史聊天，不执行数据操作。通知中心可关闭主动洞察与周报，手动聊天仍可使用。

锁屏推送只提示复盘已准备好，不展示资产金额；完整内容需要登录后查看。

选择“本地数据助手”时周报也不调用外部 AI；手选其他 provider 时尊重该 provider，但后台只使用其快速档，避免深度模型的自动费用。

页面关闭后的浏览器推送需要 HTTPS、用户主动启用通知，以及 `NEXT_PUBLIC_VAPID_PUBLIC_KEY`、`VAPID_PRIVATE_KEY`、`VAPID_SUBJECT` 和 `CRON_SECRET`。在通知中心启用，登录并连接家庭后订阅；可随时关闭。发送成功的订阅按周去重，临时失败可重试，过期订阅会清理。本机配置不能自动同步到 Vercel，部署时须将这些环境变量填写到对应项目。

`/api/advisor/digest` 只接受 `Authorization: Bearer <CRON_SECRET>`；未配置密钥时拒绝执行。服务端密钥和 VAPID 私钥不进入浏览器。
