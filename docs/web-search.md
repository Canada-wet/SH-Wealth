# 联网查证

顾问内展开“联网搜索”：自动判断、开启（可选公开主题）、关闭。选择本地助手时不调用搜索服务。偏好与已发送的来源／检索时间随家庭文档同步、备份和聊天历史保存；未发送草稿仍仅在本机。

自动模式识别时效问题，例如“查询今天央行政策利率”“最新TFSA额度”“现在CAD汇率”。账本余额、普通概念解释和明确编辑不增加搜索调用。第一版聚焦加拿大官方金融主题：政策／房贷／GIC利率、TFSA、RRSP、FHSA、CAD汇率、通胀和个人税务规则。未识别的最新话题会请用户选公开主题，不能伪装联网。

搜索与回答分离：独立 OpenAI Responses `web_search` 查证公开资料，现有路由继续选择 DeepSeek 或复杂问题的 GPT‑6。默认搜索模型为现有 OpenAI 快速模型，可通过服务端 `OPENAI_SEARCH_MODEL` 覆盖。沿用 `OPENAI_API_KEY`，无需新增搜索平台凭证；实际联网权限与额度需通过真实请求验证。

每个请求最多一个搜索工具调用，低搜索上下文、最多1400输出token，搜索超时22秒、不自动重试；联网后的回答模型预算32秒、不自动重试。沿用账号数据库限流。关闭模式、未配置key、超时、没有实际完成的搜索或没有安全官方引用时，明确标注未查证；不让模型用旧知识猜当前数字。联网有额外工具与token费用，不宣称精确金额。

## 隐私与权限

搜索输入由固定公共主题生成，不发送原始问题、家庭成员、金额、账户清单、聊天或位置明细。当前不支持任意自由查询，以避免隐私误传；可选择公开主题。日期只用于标注当前检索日。`store:false` 不代表服务商完全不处理或不保留运行日志。

网页是数据，不是指令。联网请求返回的 actions 强制为空，即使用户同时要求改账或网页含有恶意指令。需要改数据请另发明确编辑指令，并核对 App 预览。已授权的外部渠道对话也支持相同查证，仍只读；定时周报不默认联网，避免增加每周成本。

只有政府、央行与银行官方域名的 HTTPS 引用可保留，来源链接可点击并显示 Toronto 检索时间。检索时间不是行情时间：汇率、利率等可能有发布延迟，须核对页面发布日期、生效日期、期限及条件；结果不构成个人法律、税务或投资建议。

按 OpenAI Docs 核对实现：[Web search](https://developers.openai.com/api/docs/guides/tools-web-search)、[GPT‑6 Luna 支持的工具](https://developers.openai.com/api/docs/models/gpt-6-luna)。

验证：`npm test`；`npm run test:search` 为仅公共主题的真实搜索检查。界面测试覆盖偏好持久化、公共查询预览、来源可点击、聊天刷新恢复；不代表外部平台已配置或所有银行页面都能被检索。
