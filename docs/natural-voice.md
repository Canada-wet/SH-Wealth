# 自然语音对话

打开财富顾问，点击“开始对话”并授予麦克风权限即可。没有语种选择、转写确认或手动发送步骤；字幕只是辅助。说完停顿约 1.2 秒后，顾问自动处理问题、播报简短回答，接着听下一句。点“打断”结束当前播报，点“结束对话”关闭麦克风。

语音模式暂时收起模型设置、搜索设置和文字输入，留出聊天空间。已有文字草稿不因语音提问清空；结束后恢复。搜索沿用进入语音前的持久偏好，模型仍日常 DeepSeek、复杂规划 GPT‑6。

修改资产、回报、贡献或预算：自动提问后只生成差异预览，音频播报说明待确认；然后暂停收音。用户点击“确认并保存修改”或“取消修改”后才继续。伴侣已修改数据时拒绝过期预览。不会根据一句含糊的“确认”自动执行，也不会用播报作为保存成功的证据。

## 安全与成本

- 录音和合成音频仅在请求及浏览器内存中使用，不写入 Supabase、localStorage 或备份。已识别的问题、完整文字回答沿用家庭聊天保存与同步。OpenAI 是音频处理方，不能将 App 不存录音等同于供应商零保留。
- 长期 API key 只在服务器。语音接口验证两位授权成员，数据库独立限流（每分钟 12 次、每小时 80 次音频请求）。每轮通常一次识别、一次合成，文字顾问沿用每分钟 6 次 / 每小时 40 次限制。
- 语音识别默认 `gpt-transcribe`，不发送固定 language 提示；播报默认 `gpt-4o-mini-tts` / `marin`，自然语气、适中速度。两项均额外产生 API 费用，不自动重试或静默调用昂贵备用模型。
- 收音单句最长 30 秒，录音不超过 2 MB；30 秒静默自动结束，整轮最多 5 分钟 / 10 次提问。隐藏页面、收起顾问、切换会话或退出登录释放麦克风并取消等待；取消不保证服务商停止计费。
- 播报准备与播放时暂停收音，避免回声触发重复提问；不是全双工的“说话直接插嘴”模式，当前通过按钮打断。仍有语音识别、模型和合成的网络等待时间。

## 配置与验证

已有 `OPENAI_API_KEY` 即可，模型覆盖变量见 `.env.example`。数据库需运行 `supabase/voice.sql`；无权限、额度或供应商故障会明确提示并回退到文字。手机需要 HTTPS 和受支持的 MediaRecorder / AudioContext；设备权限与识别准确度需实际验证。

`npm run test:voice` 使用真实在线接口：生成中文和英文合成音频、自动识别原文、请求 DeepSeek 简短口语回复和修改计划；使用合成账本，不写真实财富。`npm test` 与浏览器测试覆盖停顿、自动发送、暂停确认、打断、晚到权限/回复、静默、降级和聊天恢复。它们不等于真人麦克风测试。

依据：[OpenAI 文件语音识别](https://developers.openai.com/api/docs/guides/speech-to-text)、[OpenAI 文本转语音](https://developers.openai.com/api/docs/guides/text-to-speech)。OpenAI Docs 指引影响本次实现：不固定输入语种、使用神经播报，并明确披露 AI 合成声音。
