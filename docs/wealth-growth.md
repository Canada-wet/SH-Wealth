# 财富增长行动台

入口：首页 `/#growth`，主导航“增长行动”和手机“增长”。延续已有私密家庭文档、双成员同步、备份、登录限制和顾问路由。没有新增自动交易、行情订阅或额外定时模型任务。

`v0.14.0` 同一区域第三个页签“财务自由”，深链 `/#financial-freedom`。与原名义净资产增长情景分开：新的测算以今日购买力、退休生活费缺口和手选可支用资金为基础，不能混用两个目标。详见[公式分析、持久化和模型边界](freedom-and-council-costs.md)。

## 从洞察到执行

- 依据最新账本识别预算缺失 / 赤字 / 留存超预算、应急缓冲与现金流动性、未知负债利率、目标差距与账户核对日期。按需展示本轮优先三项，其余可展开，不宣称为 AI 打分或确定的交易信号。
- 先保存留存计划，才能共同记录“已安排 / 用户标记完成”。行动记录是人的确认，不是银行或投资成交验证。事实改变、月度执行跨月、复盘日期到期后会要求重新复核；旧页面不得覆盖伴侣的新状态或新事实。
- 本月净出资只累计关联所选账户、日期在多伦多本月且不晚于今天的已记录投入减取出；独立历史出资、其他账户及未来日期排除。缺记录不等于没发生，内部调拨不等于新增财富，计划不提前计入资产。

## 增长情景

收支项目均有记录时，初值使用已录入预算正结余；缺任一类时默认 0。初值明确为未确认测算，不等于实际储蓄。用户确认每月留存、其中长期投入、参与复利的账户、自填年回报假设（默认 0，可负值）和复盘日期。

零收益基线 = 当前净资产 + 月留存 × 从下一个完整月到目标年末的月份数。以当前快照为基准，不追加本月已发生资金或计算本月余下天数的回报；首页月度目标参考也采用相同口径。自填回报情景只对主动选择的本金与长期月投入按月末复利；长期投入属于留存的一部分，不重复累计。其余留存只累加，其他资产估值和负债固定。不自动用房产、车辆、全部净资产或本年已录入回报推断未来收益，不自动预估房贷本金变化。结果为未计税费、通胀与外汇变化的名义 CAD 算术情景，不是业绩、概率、达标保证或投资推荐。

图表按实际月数间距绘制，年度采样与年末不足一年的最后区间不等距拉伸；目标线扩展坐标范围，数值表可核对。长期投入不能大于总留存；预算缺失、超预算及已删除的所选账户明确提示，输入无效不保存。0 回报、负回报、已过期目标、数值溢出均有校验。

已确认可动用现金只使用现金类别中明确标为“可动用”的金额；未知、锁定、不易变现资金不充当已确认应急金。必要开支或设定月数缺失时不伪造目标。负债利息只是已知余额 × 利率的静态参考，未知部分不当零；额外还款前须核对限制及费用。

## 保存与顾问

可选 `preferences.growthPlan` 兼容旧备份；纯增长计划也作为已保存用户内容，避免被当成空家庭或聊天合并丢弃。显式保存、不写实际资产 / 负债 / 出资或财务历史。配置基线与财务指纹校验防止旧草稿覆盖新数据，其他行动进度合并保留；草稿未跨刷新自动保存，离页警告取决于浏览器。

App 顾问、只读渠道顾问和现有周报使用同一计算模块及已保存计划，不读取未保存草稿。模型不可借用既有动作偷写新计划、行动进度或声称已成交；本地助手也能解释增长行动，无需额外付费调用。主动周报降级到规则内容时仍保留行动跟进，不增加发送渠道或改变已有同意设置。

手机导航横向滚动、不拆成竖排；工作台可见时收起重复的顾问气泡提醒，聊天仍可手动打开。隐私模式同时隐藏增长分析。

方法参考：[FCAC 应急金与复盘](https://www.canada.ca/en/financial-consumer-agency/services/savings-investments/setting-up-emergency-funds.html)、[安省证监会投资教育：风险与回报](https://www.getsmarteraboutmoney.ca/learning-path/getting-started/getting-started-with-investing/)。这些是一般教育资料，不替代针对家庭的专业建议。

## 验证

`npx vitest run tests/growth.test.ts tests/api.test.ts tests/insights.test.ts` 验证算术、流动性、时间边界、只读顾问事实、冲突及持久化。`E2E_USE_MOCK_AUTH=1 npm run test:e2e -- tests/e2e/growth.spec.ts` 用合成账本验证双成员保存、任务、刷新、出资跟踪、预算警示及隐私。可加 `E2E_WEBKIT=1 --project=mobile-safari` 验证 Safari 内核。显式对线上执行时只创建与清理隔离测试家庭，不修改真实财富；默认测试不调用真实付费模型。
