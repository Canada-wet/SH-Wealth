# 家庭生活空间 · v0.10.0

`lib/navigation.ts` 是全站唯一功能目录，含 32 个固定 ID。桌面侧栏、手机快捷入口、搜索、家庭首页和模块关联入口共用目录与深链接。

## 空间与职责

家庭首页 `/space` 只负责轻量状态、最多三项下一步、本人继续使用与领域入口；原 `/` 保留财富工作台，原 `/#assets`、`/#cashflow` 等链接不变。品牌入口进入家庭首页，没有明确 next 的登录默认 `/space`；不把最近使用解释为强制跳到上次页面。明确的回跳路径仍优先。

六个根空间为家庭首页、财富总览、市场、研讨、心理学和兴趣。首页固定可找到，其余根空间按置顶及最近使用排序；财富子功能的真实访问也提升财富空间。子功能置顶不自动把整个空间置顶。只有在财富工作台内才展开账本、收支、增长、成员贡献、复盘和计划二级导航，避免每个模块出现一长串无关编辑入口。

`homeSnapshot` 只从同一 `WealthState` 派生事实，不保存重复摘要或触发模型。预算缺收入或支出时结余为未知，空账本不冒充零财富；季度、账户与现金流提示复用既有规则，遵守关闭和稍后提醒偏好，并按目标入口去重。冲突 / 读取错误先显示待确认，不展示金额为最新状态。最近财务快照读取 history 的时间，不使用聊天可改变的 updatedAt。兴趣分钟与次数来自实际已记录练习，不把目标时长当完成。

`continueFeatures` 只按各具体入口自己的 `last_used_at` 排列，排除首页，不用图钉时间或父节点折叠制造访问。首页不自动读取私人研讨、生成市场简报或将家庭数据发送至其他模型。每日心理学复用已版本化的精选库和多伦多日期，不自动生成新研究结论。

## 使用方式

- 搜索按钮或 ⌘ / Ctrl K 打开功能目录；支持中英文关键词与分类。方向键选择、回车打开、Escape 关闭。搜索不发送给模型，也不记录搜索词。
- 点击图钉，将页面或子功能放在最前。置顶按加入时间保持稳定；非置顶按最近使用排序，无记录的入口保持目录次序。
- 浏览子功能（如汇率）也提升父页面（市场看板）的最近使用位置。仅实际页面 / hash 切换算使用，不追踪滚动。
- 手机顶部提供搜索、置顶 / 最近快捷入口；更多设置与退出在搜索面板底部。操作区至少 44px，财富根锚点留出 sticky 栏与安全区；父空间与精确置顶入口分别标注位置。
- 关联功能弱化为默认折叠的入口，只在需要时展开，不自动向研讨发送资产、文件或聊天。
- 搜索输入法组合期间回车不导航；方向键活动结果提供播报，关闭后焦点恢复。浏览器标题反映当前功能，多标签和历史更容易辨识。

## 保存与授权

执行 `supabase/navigation.sql`（在 access.sql 之后）。v0.10.0 原地扩展固定 ID 约束以允许 space，不删除任何偏好。独立表 `wealth_navigation_preferences` 仅保存 `user_id`、固定 `feature_id`、置顶与服务器时间；两位用户各自管理，不互相覆盖。个人导航不在家庭账本 JSON 备份中。

API 使用现有双账号白名单和验证过的登录。GET 明确限制本人，POST 只接受同源、1KB 以下的固定操作；用户 ID、时间均由服务端决定，任意 URL 不可写入。数据库只允许本人读取；修改需经过固定 RPC，内部通过 auth.uid() 认领身份并重新验证白名单。没有对共同财富数据、模型或第三方数据的调用。

图钉操作等待云端确认后才改变。访问与置顶分别更新不同字段，防止另一设备浏览页面覆盖置顶。窗口重新聚焦时读取服务器最新偏好。网络错误保留当前列表并提供重连，不假称云端已同步；首次读取失败时仍可搜索和进入全部功能。没有离线编辑置顶或后台无限重试。

手机输入框使用设备键盘；隐藏或缩小后的可见高度由 dvh 约束。对已有弹窗中的未保存表单，不用快捷键覆盖它。页面使用原生链接，保留浏览器回退和新标签打开能力，不将“最近使用”解释为强制重定向首页。
