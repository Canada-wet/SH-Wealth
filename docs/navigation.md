# 家庭生活空间 · v0.8.0

`lib/navigation.ts` 是全站唯一功能目录。桌面侧栏、手机快捷入口、搜索、首页工作台和模块关联入口均使用相同的固定 ID 与深链接，避免不同页面的入口各自漂移。

## 使用方式

- 搜索按钮或 ⌘ / Ctrl K 打开功能目录；支持中英文关键词与分类。方向键选择、回车打开、Escape 关闭。搜索不发送给模型，也不记录搜索词。
- 点击图钉，将页面或子功能放在最前。置顶按加入时间保持稳定；非置顶按最近使用排序，无记录的入口保持目录次序。
- 浏览子功能（如汇率）也提升父页面（市场看板）的最近使用位置。仅实际页面 / hash 切换算使用，不追踪滚动。
- 手机顶部提供搜索、置顶 / 最近快捷入口；更多设置与退出在搜索面板底部。
- 首页保留同一个家庭账本，工作台仅提供快捷入口，不复制财富数据。关联功能不会自动向研讨发送资产、文件或聊天。

## 保存与授权

执行 `supabase/navigation.sql`（在 access.sql 之后）。独立表 `wealth_navigation_preferences` 仅保存 `user_id`、固定 `feature_id`、置顶与服务器时间；两位用户各自管理，不互相覆盖。个人导航不在家庭账本 JSON 备份中。

API 使用现有双账号白名单和验证过的登录。GET 明确限制本人，POST 只接受同源、1KB 以下的固定操作；用户 ID、时间均由服务端决定，任意 URL 不可写入。数据库只允许本人读取；修改需经过固定 RPC，内部通过 auth.uid() 认领身份并重新验证白名单。没有对共同财富数据、模型或第三方数据的调用。

图钉操作等待云端确认后才改变。访问与置顶分别更新不同字段，防止另一设备浏览页面覆盖置顶。窗口重新聚焦时读取服务器最新偏好。网络错误保留当前列表并提供重连，不假称云端已同步；首次读取失败时仍可搜索和进入全部功能。没有离线编辑置顶或后台无限重试。

手机输入框使用设备键盘；隐藏或缩小后的可见高度由 dvh 约束。对已有弹窗中的未保存表单，不用快捷键覆盖它。页面使用原生链接，保留浏览器回退和新标签打开能力，不将“最近使用”解释为强制重定向首页。
