# 自选行情刷新修复验证

版本 0.17.2，2026-11-09。范围仅市场页刷新接线与状态说明，不改家庭账本、自选配置、SQL、凭证或定时任务。

- 全量 Vitest 1,052 项通过、21 项外部条件集成跳过；新增 4 项组件/页面回归用例。TypeScript 与隔离生产构建通过。
- 统一页头、速览、股票区三个整组刷新入口，覆盖速览卡片、行情表、汇率与已打开图表；保留搜索、市场筛选和选中证券。单卡重试保留。
- 暂停外部行情时不隐式授权；屏幕外卡片不设置外部 src。重连重置状态和高度，旧窗口消息不得伪造新连接就绪。
- 时间明确为重连请求时间（Toronto），不是报价观测时间；组件响应不冒充已获得最新价格。
- CUA 预览使用实际市场页及报价组件，家庭上下文和官方 API 为隔离夹具，不登录或写入真实家庭。仅向 TradingView 发送公开 NVDA、META、XIC、ZGIN 代码；窗口返回公开报价并自行标注延迟，不将其写入应用市场数据。
- 1440px 桌面及 390px/320px 手机尺寸无横向溢出；手机刷新按钮为 44px。刷新后搜索与选中图表保持，暂停后 iframe 数量归零。
- GitHub Actions 使用离线身份与行情夹具运行浏览器测试；最终 CI 与部署状态以相应运行记录为准，不用本地预览冒充上线验证。
