# 家庭季度复盘（v0.3.0）

入口：`/#quarterly-review`，左侧「季度复盘」、手机「复盘」及首页季末提醒。

## 流程与数据口径

1. 默认选择多伦多时区最近已结束季度，1/4/7/10 月起提醒；历史季度可回看。
2. 期初前及期末前最近快照按真实时间排序选取。重算资产减负债，不使用演示曲线或当前余额。两个点不是精确季度边界，也不是投资回报；未记录不是零。
3. 贡献按账本发生日和成员筛选，投入减取出，不自动再加到资产、不假定涵盖全部储蓄。归档时保存该次计算结果。
4. 历史预算和目标仅取期末前快照；不以当前预算补历史，不将月预算乘三当实际季度现金流。
5. 四项核对、笔记和至少一项有负责人与到期日的行动后可归档。允许明确记录缺口；不强制编造估值/回报。
6. 归档后正常编辑只允许行动完成状态，证据和结论不随现有账户改动；其他往季未完成行动在当前复盘提示。备份恢复仍可恢复旧数据，不宣称数据库不可变审计。
7. 笔记离开输入框保存，另一设备改动时保护输入中的草稿并拒绝覆盖。其他变更使用现有家庭文档 CAS；冲突时本机保留且明确报错。
8. AI 按证据和缺口只读引导，由用户主动打开/发送；提醒本身不调用模型、不产生后台模型费用。

## 提醒与隐私

- 首页提醒默认开启，支持暂停与延后七天。全局主动提醒关闭时也暂停。
- Vercel 每日 16:00 UTC 检查（多伦多夏季中午、冬季上午 11 点），不是依赖本地 Mac 的任务。只检查最近已结束季度。
- 每家庭/季度生成一个确定 ID 的站内提醒，归档、延后或关闭时停止；旧季度云端提醒不继续显示在当前主动提醒列表。
- 外部季度提醒默认关闭；家庭设置开启且成员本人已启用通知渠道后，可发送邮件/Telegram。锁定为静态无金额提醒并回到私密 App，不发季度财务证据。
- 复用服务端 `claim_wealth_channel_delivery` 原子发件箱，发送前重新核对渠道启用、授权成员及提醒家庭匹配；成功或状态不明不自动重发，明确拒绝最多按既有策略重试三次。
- WhatsApp 缺少季度模板，不发送。不自动开通新渠道；邮件依赖 SMTP/Resend，不宣称现有项目已可向所有邮箱投递。
- 定时入口自行验证 CRON_SECRET；未授权不读取数据库。沿用家庭文档成员 RLS，无新增公共数据表。

## 验证

- 单元：时区/夏令时/跨年、历史边界、无历史、贡献、归档、提醒偏好、备份识别、服务端去重/鉴权、通知内容与渠道。
- 浏览器：桌面/手机/WebKit 的完整核对、笔记、行动、归档/刷新、隐私、导出和提醒开关。
- 实际 Supabase：只在临时合成家庭验证双成员同步，绝不测试修改真实家庭文档。测试不发送真实通知、不调用付费模型。
