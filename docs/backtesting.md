# 投资回测工作台

实现版本：0.15.0，2026-10-31。入口 `/backtest`，加入统一侧栏、搜索、最近使用和个人置顶。此模块是独立研究沙盒，不执行交易、不改真实账户、贡献或财务历史。

## 使用与数据选择

1. 输入股票／ETF代码、权重和资金假设。最多8个唯一标的，权重100%。`.US` 表示美国交易代码，`.TO` 表示多伦多交易代码；请核对具体证券及其成交币种，不自动模糊匹配。
2. 导入有使用权的 CSV，或完整 JSON 研究包；也可明确选择合成演示。演示使用 `DEMO1.US / DEMO2.US`，不是真实证券价格。无真实行情时不回退到假数据。
3. 运行后并排比较，查看事件与年度表现。改动参数后旧结果保留但标记过期，必须重新运行才能交给AI。
4. 保存命名计划到现有家庭JSON。导出研究包包含配置和原始导入数据，导入后重新计算，不信任外部提供的结果。

现阶段真实数据入口是CSV，尚未开通、接入或实测任何付费历史供应商。统一数据接口是 `BacktestData / HistoricalAsset / PricePoint`；将来供应商适配器须输出同一验证过的结构。不要把 TradingView iframe 当成数据API。

### CSV口径

| 模式 | 必需列 | 处理 |
|---|---|---|
| 原始成交收盘价 | `symbol,date,close,dividend,split` | 无事件填0、1；split为新股数/旧股数；dividend为当日实际每股除息金额 |
| 总回报复权 | `symbol,date,adjusted_close`，也接受 `Adj Close` | 已含拆股和分红，不重复加计；累计分红未知，仅支持再投资口径 |
| 仅拆股复权 | `symbol,date,close` | 不再调整份额，不加分红；展示明确的价格回报限制 |

单证券文件可不含symbol列，但需在界面指定准确代码。日期为YYYY-MM-DD，数值不用千位逗号；支持CSV引号、BOM、CRLF，按日期排序，拒绝重复日期、空白数值、零价、公式和坏公司行动。CSV最多8MB，JSON研究包最多20MB；每标的最多15000个日线。

第一版只支持同一种计价币种USD或CAD，不模拟跨币种历史汇率。该限制避免把美元价格与加币家庭资产直接相加。TSX的美元单位等特殊证券不能仅凭交易所推断币种，导入前须核对。

### 供应商建议（待用户决定）

- 优先评估 [EODHD](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes)：官方列出全球日线与价格口径，[分红和拆股接口](https://eodhd.com/financial-apis/api-splits-dividends)独立提供。官方价格入口从US$19.99/月起，但具体套餐、目标加拿大ETF、公司行动、家庭两成员内部使用授权必须另行确认。不能把最低起价理解为包含所有端点和许可。
- [Alpha Vantage](https://www.alphavantage.co/documentation/) 的 Daily Adjusted 属于付费端点；[Twelve Data](https://twelvedata.com/pricing) 需核对交易所、历史和公司行动权限。这里没有注册、购买或升级服务。
- EODHD适配时必须区分 raw `close` 和已含分红的 `adjusted_close`；raw价格需匹配实际历史每股 `unadjustedValue`，不能混用按今日股数调整的 `value`。必须获取完整拆股、币种和公司行动，不得在端点报错时默认为无事件；固定供应商域名、鉴权、超时、配额、按次明确用户触发，无自动重试。

## 可复现方法 v1

所有策略使用相同起始资金及后续月供；月供在每月首个共同交易日收盘加入，首月不再重复追加一次月供。交易允许碎股，单边费率为用户输入的手续费与滑点bps合计。

- 买入持有：首日部署本金；之后每笔新增月供按目标权重买入，不卖出再平衡。
- DCA：把原有本金分为指定月份，从首日开始逐月部署；新增月供到达即买入。尚未投入的本金仍属于账户现金并参与收益和回撤计算，不能从分母消失。
- 年度再平衡：首日部署，每年首个共同交易日将投资部分调回目标权重，卖出和买入均扣费。现金分红模式下分红和现金利息不强行用于调仓。

现金按用户固定年率、实际日历天复利计息。拆股先调整持有份额，分红只给除息日前已有的份额；当日收盘新买入份额不再领取当日分红。为简化，分红于除息日记账并可同日再投资，不模拟支付日、预扣税、结算、外汇点差或融资。基金管理费若已体现在价格中不再次扣除。

| 指标 | 定义 |
|---|---|
| 净值/TWR | 以100为初始单位净值，在外部资金进入前按当时净值发行单位，剔除新增投入的假增长；初始交易费仍计入 |
| CAGR | 净值总回报按实际365.25日年数几何年化；短于一年醒目警告，溢出显示未知 |
| XIRR | 实际投入日期的负现金流与期末全部账户价值的正现金流折现率；不是TWR的别名 |
| 最大回撤 | 单位净值相对此前峰值的最大跌幅，包含未投入现金的影响 |
| 年化波动/Sharpe | 日收益样本标准差×√252；Sharpe为平均日超额收益/标准差×√252，固定无风险年率转为日率；无波动时不报告Sharpe |
| 分红、利息、费用 | 单独累计，均已体现在账户价值/回报中，不能再次与总收益相加；缺分红明细不显示0 |
| 恢复 | 最差回撤峰值至之后首次恢复该峰值的日历天数；期末未恢复显示未恢复 |

参见 [CFA Institute：Rates and Returns](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/rates-and-returns)。并不复刻机构绩效归因或GIPS认证。

### 日历、事件与偏差

统一使用全部持仓的共同有效日期；上市前/退市后不填价格，实际区间缩短明确提示。若区间内部标的日期不一致，直接拒绝，避免遗漏交集筛掉的分红/拆股。共同日期相邻超过7天，或超过90天的样本密度低于180个观测/年，拒绝按日频风险计算。尚无官方逐交易日历核验，因此所有标的共同缺一个小缺口仍可能无法检测；用户必须核对源文件完整性。

事件是事后策展的观察窗口，不参与交易逻辑，包括1987年10月、2001年NBER衰退月份、全球金融危机NBER衰退月份、2020年疫情窗口与2022日历年。来源保存在 `lib/backtest-events.ts`。窗口不是市场峰谷精确界定，也并非完整危机列表。

事件回报从窗口前最后一个共同交易日计算；无前值则从首个观测算。窗口局部回撤与全期间最大回撤分开。完整、部分和未覆盖分别标注，不把缺失当零风险。绘图最多约1500点，计算始终全日线，图形抽样可能隐藏短暂日内/日间变化，应以指标与完整研究数据为准。

当前证券选择有幸存者/选择偏差，事后优化权重有过拟合风险。历史不能决定未来概率；无历史风险不表示未来无损失。未包含市场冲击、交易停牌成交限制、税收与真实账户适当性审查。

## 持久化、隐私与AI

- 命名配置（最多12份）位于 `WealthState.preferences.backtestLab`，通过现有家庭JSON版本/CAS同步，不追加金融快照。保存旧已选计划时检查载入基线，避免另一个窗口新配置被旧草稿覆盖。
- 行情、有效草稿、最近40条研究对话位于按家庭ID隔离的浏览器IndexedDB；不放进共享财富大JSON。缓存失败明确提示导出。此缓存不是云端备份，清除浏览器数据会删除；新设备加载家庭计划后需重新导入价格研究包。
- 对话导出单独为Markdown，不自动包含财富快照。研究包不包含聊天或真实家庭数据，但用户自定义计划名称和用途可能含私密信息，分享前自行检查。
- AI为显式提交的只读研究，默认省钱DeepSeek，也可自动路由，复杂问题可能使用旗舰并产生费用。服务端重新执行回测，不接受客户端伪造的收益结论。现有顾问额度RPC在调用前检查，无自动重发。
- 家庭背景默认关闭；开启后仅发送净资产、现金参考、预算完整性和目标，不发成员、逐项资产和全局聊天。关闭/开启时新建研究上下文；恢复本机私密对话不会自动重新授权，其历史在未授权请求中被剔除。
- 当前公开宏观/情绪观测需另行勾选，使用现有固定官方源并附观测日期；可能滞后、缺失或抓取失败，不作为实时行情/崩盘预测。模型无下单、浏览器控制、文件执行或账本写权限。

- 已有数据库仅增量执行 `supabase/backtest-navigation.sql`（依赖原导航表），更新个人置顶/最近使用的功能白名单；不要重跑旧schema或改写既有迁移。此文件已加入校验清单，但本地校验不等于生产执行。
- 核心计划沿用原JSON存储，不需要新财富表。没有新增付费API密钥要求。上线与数据供应商开通均需另行处理，不因本地build成功而声称已上线。
