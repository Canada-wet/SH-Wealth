# 十项共同维护体验深化

围绕同一家庭文档优化，不另建一套金额来源。旧备份兼容，新可选资料随 Supabase、完整 JSON 备份和财务快照保存。

1. **批量估值表**：在资产负债表点击“批量核对”，逐行改价值和本年回报。编辑自动勾选，只有勾选行保存；回报空白清空原值，支持负数和零。一次提交、一份快照，任一无效行不部分写入。
2. **账户资料**：添加估值实际核对日期、流动性状态和备注。可选、不猜测；顾问可能读取备注，不应写密码或完整账号。编辑回报与 AI 更新余额保留已有资料，不伪造核对日期。
3. **逐项更新检查**：现金流附近的“账户更新检查”列出日期未知、超过 30 天或未来日期的账户，可直达编辑或批量表格。已有日期时主动顾问也提醒过期项；聊天或预算更新不会掩盖旧估值。明确锁定 / 不易变现现金从应急金参考排除，未知流动性仍单独提示，不冒充可用现金。
4. **安全撤销**：当前页面的最近一次手动或顾问财务修改可撤销，联动恢复资产、负债、贡献、收支和目标，原操作与撤销都保留历史。保留当前聊天和偏好；之后任何财务、成员或计划变化让撤销过期，防止覆盖伴侣更新。刷新后不保留撤销入口，可通过完整历史核对后编辑；不是回滚数据库。
5. **历史差异**：在“历史”中选较早、较晚快照，按账户 ID 比较新增、删除和资产 / 负债余额变化，同时显示净值变化。负债余额增减不是净值贡献的同向变化；不把记录变化当投资收益。回报、贡献和预算细节继续保留在原快照中。
6. **目标储蓄节奏**：“目标与共同安排”汇总目标差额、至目标年末的约剩余月份和零收益月储蓄基线，与首页采用同一规则。只有收入和支出都已录入才比较预算结余；预算结余不等于实际储蓄。过期期限不算无限或负月份。
7. **共同开支分摊**：可选择均分或按双方各自已录入收入比例，选择保存在家庭计划中，金额精确到分。个人开支不参与；缺一方收入不会默认为零。测算份额不是已付款，不自动增加贡献或转账。
8. **负债成本核对**：负债可填年利率及计划月还款，留空是未知，0% 是无息。静态利息仅当前余额 × 年利率，显示未知项数量；非银行账单或房贷摊销，不自动把还款加入现金流，避免重复计支。
9. **隐私遮挡**：顶部眼睛按钮隐藏全部财务内容、图表与顾问，关闭正在进行的语音；同一浏览器会话刷新保持。数据不变。不是退出登录、加密或访问控制，仍可在开发者工具中看到本机数据。
10. **编辑保护**：关闭、取消或 Esc 放弃已编辑表单前确认；不增加查看型弹窗的步骤。现金流、普通资产表单和批量表都在实际提交时核对最新数据，伙伴更新后不覆盖旧草稿。

所有金额测算均以 CAD 记录，未启用投资交易、自动转账或读取邮箱。默认收起共同安排和复盘面板，按需展开；无需增加新的服务凭证。

验证：纯计算与并发保护单元测试、桌面与手机交互，以及真实 Supabase 临时家庭中新资料的保存和双成员读取；不改写真实家庭财富。
