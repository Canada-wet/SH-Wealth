# 市场看板

入口为 `/markets`，首页桌面导航“市场看板”、手机导航“市场”。保留既有 Next.js / Supabase / Vercel、登录白名单、家庭版本冲突保护和备份格式，不创建新家庭或迁移财富数据。

## 每日市场简报（2026-10-15）

界面按“提要 → 主题联动 → 接下来关注”组织。情绪、经济前瞻、AI 产业三个按钮同时切换解读和相应指标，不再同时铺开所有正文；切换只改变浏览状态，不重新生成简报或写家庭数据。解读明确标注生成时快照，指标明确标注最新可用观测，保留逐项日期与归档警告。来源可展开核对，切回主题保留已展开状态；无有效主题时显示空态，不借用别的主题凑数。费用、生成时间和边界收进说明，身份降级标记仍始终可见。提要旁可直接跳到自选涨跌。手机压缩重复返回入口和页头说明，保留主导航、刷新、导出与同步状态；不删除实际功能。

页首新增每日简报与指标，导航“每日简报”可直接进入。情绪：Cboe VIXCLS / VXVCLS 日收盘与严格同日比值，引用 FRED 来源与版权，不伪装实时行情或 VIX 期货曲线。前瞻：劳工部 ICSA 季调初请（周六截止），Census/HUD PERMIT 季调折年建筑许可；周差只用恰好相邻一周。AI 供需代理：Census A34SNO 新订单、Fed IPG3344S 行业实际产出、CAPUTLG3344S 产能利用率，均为月频。A34SNO 明确不含半导体新订单；美国行业指标不代表全球先进 GPU / HBM / 封装供需，不计算虚假的缺口、GPU 租价或缺货率。Census 数据中心建设支出仅提供原始资料入口，尚未自动取数，不把建设支出当总 AI 资本开支。

简报只使用固定公开序列，排除外汇解读和所有家庭、自选名称、聊天信息。复用已有低成本自动路由（DeepSeek 优先）；模型叙述须覆盖有数据的三类主题并引用真实非空 ID，错误 / 缺数据明确降级为规则摘要，不冒充 AI。叙述按文本呈现，来源、数值和日期由程序固定生成，模型不生成链接。模型解释仍可能有误，引用存在不保证结论正确。月份/季度日期是统计期起点，不是发布日期或“发布滞后天数”。

`market_daily_briefings` 独立存储公共简报，保留历史、界面读取最近 7 份；不写家庭文档或财务历史。RLS 只允许已验证白名单读取，客户端不得写入或领取任务。服务端按多伦多日期领取，单日主键、5 分钟过期租约、fencing token 和最多 3 次崩溃恢复尝试避免并发重复生成；正常已完成日期不再次调用模型。首次打开可补齐当天，页面刷新与历史选择仅读取。定时入口 `/api/market/briefing/daily` 独立验证 CRON_SECRET；Vercel 每日 `0 14 * * *`（UTC），多伦多夏令时约 10 点 / 冬令时约 9 点，Hobby 调度可能在该小时内延迟。与既有周报并存，不自动发送外部通知。

指标沿用公共接口和浏览器缓存；旧备份无 indicators 字段仍兼容。部分失败保留原观测日期，不用读取时间冒充新数据。月度数据不会每天产生新观测。AI 每天共用一份，使用已有 API 用量，没有购买行情或增加付费订阅。测试浏览器默认拦截简报接口，避免合成家庭回归测试意外调用真实模型。

## 专业研究视图

市场页保留固定左侧主导航和“市场看板”当前页高亮，可直接返回家庭总览、资产、现金流、贡献与计划；手机使用轻量主导航。跨页返回锚点会在家庭数据载入后定位，不改账本。页内导航串起每日简报、自选、投资研究、概览、宏观研究、收益率曲线与汇率。

概览展示通胀、就业、GDP 和期限利差，各自标注统计期间；不把不同月份 / 季度拼成一个实时经济评分。宏观研究提供 6 / 12 / 24 期窗口、总体 / 核心 CPI 同比双线、非农新增趋势和连续三月平均；可展开观测值表。双线只画共同期间，横轴按统计日期，不补缺月。CPI / 失业率 / GDP 的前期变化用百分点；非农用千人；外汇日变化用相对百分比。月度 / 季度比较要求相邻期间，缺失不拿更早值替代。

收益率曲线固定六个期限，使用最近的共同观测日期；可比较前 20 个共同观测日，只有足够历史才绘制比较线。期限横轴等距分类，不冒充时间等距；最新逐项读数与共同曲线日期分开说明。10Y−2Y、10Y−3M 同日计算 bp；100 bp 等于 1 个百分点。展开表格可核对曲线值与历史差。倒挂仅描述期限关系，不等于确定的衰退预测，也不当作交易指令。

所有研究计算来自现有官方序列，不新增付费模型调用。不展示没有数据支持的市场一致预期、惊喜指标、胜率、风险评分、组合回报或持仓权重。自选不代表家庭持仓。官方 BLS / BEA 日历只作为入口，不伪造下一次发布日期。

## 操作闭环与故障恢复

### 投资研究与风险流程（2026-10-14）

- 速览新增半导体、数字平台、工业与基础设施、公用事业与医疗、区域与金融、宽基与主题基金、黄金与比特币、待分类等人工研究分组。按交易所和代码匹配，不猜测新增证券。可与币种 / 搜索交叉筛选；这是研究目录，不是 GICS、最新持仓穿透、资产权重或相关性测量。
- “投资研究”与图表共用所选代码。按标的记录投资逻辑、主要风险、失效条件、下次复盘日期；到达用户设定日期后显示本地复盘入口，不伪称财报日或推送服务。每项最多 2000 字、最多 120 只历史标的；从自选移除不会删除笔记，重新添加同一交易所代码可继续查看。
- 记录放在可选 `preferences.marketResearch`，沿用本机版本校验、Supabase 私密家庭文档、完整备份与恢复。旧文档无需迁移。只存笔记也算用户数据，不按空文档覆盖；财务历史与资产数值不受研究操作影响。笔记不发送给行情提供商，也不包含在“官方市场快照”导出中。
- 显式保存，不把草稿伪称已同步。切换标的保留本次页面的草稿；有草稿时触发浏览器离页提示（浏览器 / 手机系统不保证显示），未保存草稿不会跨刷新保留。同一标的保存前校验最初基线，冲突保留草稿并提示；其他标的更新不互相覆盖。云端冲突或存储失败保持既有保护机制。
- 压力试算是用户手填假设，不自动绑定行情、推测真实持仓或发送交易。CAD 报价模式不加外汇；外币模式使用 `(1 + 资产价格回报) × (1 + 每单位外币的 CAD 价值变化) − 1`。汇率正值代表外币相对 CAD 升值，与看板的 1 CAD 兑外币方向不同。显示期末金额、账面盈亏和数学回本涨幅；归零不显示虚假有限回本率。未计分红、费用、税与对冲成本，不留存试算输入。
- YINN 明确单日三倍目标，不能把多日指数累计回报乘三；ZQQ 明确加币对冲，不能在 CAD 报价收益上重复添加美元变化。不是“低风险”评级，也不保证对冲完全有效。资料核对日期与发行人链接可见。

官方参考：[Direxion YINN](https://www.direxion.com/product/daily-ftse-china-bull-bear-3x-etfs)、[BMO ZQQ](https://www.bmoetfs.ca/etfs/zqq-bmo-nasdaq-100-equity-hedged-to-cad-index-etf)、[SEC 杠杆 ETF](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-alerts/sec)、[SEC 国际投资与汇率](https://www.investor.gov/introduction-investing/investing-basics/investment-products/international-investing)。不会通过证券价格的跨域窗口反推组合持仓、收益或风险评分。

- 行情授权开关放在页首。未开启时点击证券，会定位到图表区并说明如何授权；不会只展开空白。开启后立即请求行情窗口，不依赖滚动触发懒加载。
- 每个跨域窗口有加载、迟缓、重新载入和提供商替代入口。“文档已载入”不等于“报价成功”：受跨域安全限制，本站无法读取窗口内部的价格或权限错误，不将 iframe 的 load 事件当成报价成功。ZGIN 直接给出 BMO 官方入口，不再生成已知不可用的图表窗口。
- 自选支持编辑代码、交易所和名称、删除后撤销；重复代码拒绝，编辑期间其他页面更新自选时拒绝覆盖。操作只更新自选，不改家庭资产或财务历史。保存提示区分本机写入与云端确认；版本冲突继续交由既有家庭同步界面处理。
- 只有自选、没有资产的新家庭，以及明确删除到空的自选，也作为已保存数据参与连接判断，不会被空家庭自动吞掉。两个不同版本的自选不以聊天合并方式静默丢弃。
- 官方数据在浏览器允许存储时缓存。离线重开显示原读取时间及“缓存快照”，不会伪装刚更新；坏缓存忽略，坏响应不替换好快照。部分源返回空值时保留对应旧观测、原日期与失败提示。页面的读取时间是最新接口读取尝试，不代表每个保留的指标都已更新。
- 首次取消请求后可立即重试，兼容开发 StrictMode；浏览器不必支持 AbortSignal.any / timeout。25 秒超时后结束等待，并提供重试。401 / 403 提供重新登录回市场页的入口。
- “导出官方快照”真正下载 JSON，只含公共官方序列、源日期和证券代码；不包含家庭账本、聊天、自定义证券名称或跨域报价。导出提示为请求下载，是否被浏览器保存应看下载记录。
- 已有有效且验证通过的登录可自动返回目标页；显式重新登录不会自动跳走。网络失败、频率限制与错误密码分别提示；密码可临时显示核对。市场页可退出当前设备，不主动注销其他设备。
- 登录、行情开关和退出等客户端控件在 JS 未就绪前保持禁用，避免静态首屏看似可按而实际无处理器；未就绪过久会提示启用脚本或刷新。退出由市场页统一跳转，避免重复导航导致刚输入的状态丢失。

官方数据服务器缓存 300 秒，页面可手动刷新，前台约 5 分钟核对一次，后台隐藏时暂停轮询。读取时间与源数据观测日期分开。宏观日期代表统计期间，不冒充发布日期；历史值可能被官方修订。10Y−2Y 只在同一天的有效观测齐全时计算，以 bp 表示。

数据源错误显示“暂不可用”，不填示例数值、不把缺值当零。整次刷新失败保留上次成功结果及其日期。混合频率的 FRED CSV 请求可能返回 ZIP，故宏观序列逐项请求，日频国债统一请求。

## 自选与标的

用户清单去重为 30 项，包括 NVDA、META 和 **NASDAQ:SPCX（SpaceX）**，不替换成旧 SPAC ETF 的 SPCK。CLS 默认 NYSE 的 USD 版，可另加 TSX:CLS；RBOT 使用 TSX 的 CAD 版。CGL.C / DATA.B 保留原始点号，不能改为下划线。

支持按代码 / 名称 / 交易所搜索、添加、删除、查看图表；最多 60 项。同代码不同交易所视为不同标的。自选作为可选 `preferences.marketWatchlist` 随私密家庭文档共享、跨设备保存和导出恢复；旧备份无该字段仍可使用。仅查看行情、搜索、切图和换算不写家庭数据；编辑自选不产生财务历史快照，也不改变资产估值。遇到本机与云端版本待确认时，先返回家庭页处理，再修改自选。

2026-10-14 实际窗口检查中，ZGIN 没有可用报价，保留代码并提供 BMO 发行方页面，不替换基金，不使用 NAV 冒充市场价格。其他标的也可能受行情覆盖、权限、市场休市、网络或浏览器阻断影响。个别空白不代表价格为零。

## 自选涨跌速览

### 工作台体验

区块导航固定在顶部，并随滚动高亮当前位置；手机导航横向滑动但页面本身不横向溢出。市场页单独处理锚点留白，避免家庭首页手机顶栏的偏移影响市场定位。图表区提供返回速览入口，返回后重复点击同一证券仍重新定位，已有图表不因此重建或重置。

速览有独立搜索，支持代码 / 名称 / 交易所、清空、Escape 和无结果重置，不影响下方管理清单。全部 / 美股 / 加拿大筛选显示标的数量。紧凑 / 舒适布局保存在本机 `together-market-layout-v1`，不写家庭文档或历史；禁用浏览器存储时仅保留本次切换。搜索结果少时不拉伸卡片填满整屏。

压缩行情连接条，将隐私细节与口径解释收进可展开说明；保留授权操作、数据来源、延迟与缺报价提示。正常就绪卡片不再重复播报状态，错误状态仍显示；手机保留至少 44px 的卡片操作热区，键盘焦点可见，支持系统减弱动画偏好。

看板前部的 `自选涨跌` 导航直达速览。沿用同一份家庭自选，不另存一份清单；添加、编辑、移除及撤销同步反映。下方搜索只过滤管理区，速览始终覆盖所选市场的完整清单。支持全部、美股 USD、加拿大 CAD 筛选，并通过选择器打开本站详细图表。筛选与选图只是浏览状态，不改账本。

独立 TradingView 单证券卡片显示最新价格、相对前收盘的日涨跌额和百分比；不把日涨跌称为个人收益，也不汇总不同币种。不是逐秒实时分发行情，延迟及交易时段以提供商标注为准。ZGIN 当前不覆盖，保留原代码、显示破折号和发行方官方入口。其他用户新增代码仍可能不被覆盖，不能保证窗口数字完整。

桌面多列、手机单列，每项价格和涨跌同时可见，不用横向轮播掩盖剩余项目。试验发现 Tickers 紧凑窗口按宽度只显示部分代码，而窄版 Market Quotes 表会裁掉涨跌列，均不用于速览。最终采用 Single Ticker 专用报价卡片；iframe 使用浏览器原生 lazy 按需加载，避免首屏同时加载整张长列表。每张可重试、核对来源，点击卡片代码进入本站图表。不读取跨域报价来编造涨跌家数或榜单。沿用外部行情授权开关，暂停即卸载；仅发送公开代码及交易所，不发送用户自定义名称或家庭数据。详见 [TradingView Single Ticker](https://www.tradingview.com/widget-docs/widgets/tickers/single-ticker/)。

## 安全与授权

`GET /api/market` 验证既有两个授权账户，客户端响应 `private, no-store`，不提供未登录行情接口。服务端只访问固定公共序列，不转发家庭金额、原始聊天、任意 URL 或客户端查询参数。公共缓存中没有家庭数据或认证信息。不新增市场 API key，不调用付费 AI。

第三方行情默认不加载，用户启用后使用独立跨域 iframe；不把第三方脚本注入财富页面。iframe 仅收到公开代码和图表配置，不发送用户自定义名称，提供商仍会获得连接 IP / 浏览器信息。开关仅保存于本机，暂停即卸载窗口。来源链接、提供商品牌和数据延迟提示保留。

这不是全交易所授权的逐秒报价服务。TradingView 网站订阅不等于允许在 App 中分发实时证券数据；若需要股票交易级实时报价，须另接具备对应交易所分发许可的服务，不能靠去掉 D 标记实现。看板不交易、不推荐买卖、不覆盖用户手动账本。

## 复现

默认单元与浏览器回归使用合成数据、隔离身份、受控行情窗口，不调用行情网站。

`npm run test:market` 显式检查真实官方汇率、六项美债和五项宏观数据；不修改家庭数据。

在已按离线身份构建 `.next-test` 后，`RUN_MARKET_WIDGETS=1 E2E_USE_MOCK_AUTH=1 npm run test:e2e -- tests/e2e/market-widgets.live.spec.ts --project=desktop` 显式检查真实第三方窗口的数字报价及图表。该测试仅使用合成临时家庭，结束后清理。不能用测试通过承诺每个标的、所有设备或未来时刻都有报价。
