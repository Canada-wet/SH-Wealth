# v0.2.0 · 市场 × 家庭决策

## 先关联，再解释，不自动改账

市场页新增 `#market-wealth`。每个账户可把已核实比例关联到指定交易所与证券，合计不能超过 100%，同账户同证券不重复。金额取自当前 CAD 账户估值；自选、账户名称与报价币种不自动生成持仓。未关联部分与已删除账户分别提示。保存关联不修改资产 / 负债 / 出资 / 财务历史；配置与账户金额基线拒绝旧草稿覆盖。纯关联家庭也属于已保存文档，兼容旧 JSON 备份和双成员同步。

关联金额按账户估值与保存比例重算，而不是实时券商份额。相同证券跨账户合并，ETF 不穿透。外币敞口必须明确选定，CAD 报价不等于没有外币风险，未核实不当零风险。官方央行汇率与 VIX 只有合法、非未来、近 7 天观测才形成带源日期的文字；缺数不猜。现金缓冲使用统一现金分类 / 流动性和收支记录，不把锁定或未知现金当已确认可动用金额。

压力试算只对关联部分计算：`CAD金额 × [(1+统一价格冲击) × (1+已确认未对冲外币相对CAD冲击) − 1]`。CAD / 对冲 / 未知部分不追加汇率冲击。其余资产、债务不变；不计税费、相关性、杠杆路径和 ETF 穿透，不是 VaR、预测或今日盈亏。结果连接假设净资产、家庭目标差额，以及相当于多少个月已保存计划留存；不叫预计回本时间。

顾问按钮只带入草稿问题，不自动发问。App 顾问在相关市场问题且已有账户关联时读取服务端固定官方数据；客户端不能传入任意报价或外部 URL。家庭数据只进入已有授权模型，不进入公共行情请求、市场日报缓存或搜索关键词。只读消息顾问和周报也包含已保存配置，但不声称获取了当前证券报价。隐私模式隐藏新联动区。

市场口径：[央行日均汇率](https://www.bankofcanada.ca/rates/exchange/daily-exchange-rates/)、[Cboe VIX 定义](https://www.cboe.com/tradable-products/vix/)。行情窗口仍由提供商控制；没有抓取跨域价格并推算真实账户收益。

## 每日心理学

`/learn` 首批 8 个带原研究 / 作者讲座链接的精选模型。每天按多伦多日历固定轮换，分别说明投资、工作、生活应用、一个可控练习和适用边界。应用案例是编辑推演，不是研究已证明的投资收益或治疗效果。上线日为 2026-10-15，回看最近 120 天；不展示未来卡片。v1 目录顺序和调度长度固定，后续新增版本不得改写旧日历映射。

收藏和每日订阅放在 `wealth_learning_preferences`，以家庭与认证用户为键，由 RLS 隔离，不混入共同家庭文档或共同备份。GET 不创建偏好；保存显式带版本，冲突返回 409。实际用户 ID 来自认证而不是请求。未保存 / 超时不显示成功，支持重新读取确认。

`/api/learning/daily` 每天 15:00 UTC 调用，独立检查 Cron secret；多伦多夏令时约 11:00 / 冬令时约 10:00，Hobby 调度可在该小时内延后，见 [Vercel 调度限制](https://vercel.com/docs/cron-jobs/usage-and-pricing)。只有本人明确订阅才发送，首次从下一次任务开始，不补发。Web Push 仍需浏览器权限及可用订阅，Email / Telegram 需既有验证连接及发送凭证。WhatsApp 未配置本类模板，明确不发。

投递先调用 service-role 专属原子认领函数，核对当前订阅和多伦多当日；按家庭、用户、日、通道、目的地哈希去重。关闭后不再认领新投递，但已开始的投递可能完成。发送超时 / 崩溃不自动重试，避免重复，状态区显示已接受 / 失败 / 不确定 / 待确认。平台接受不等于设备送达或已读。独立 ledger 不复用周报 last_alert_id，避免日/周提醒互相破坏去重。不向通知发送家庭金额。

部署前执行 `supabase/learning.sql`。测试 `tests/learning.sql` 只创建事务内合成家庭，验证伴侣 / 白名单外隔离、非服务角色不能认领、当日去重、旧日拒绝和关闭订阅，最终回滚。

## 暂停与重新开启（v0.14.1）

按用户要求，默认暂停每天的卡片轮播和对应提醒。新旧家庭缺少设置均按暂停处理，默认卡片固定在2026-10-25（不以每次访问的“今天”伪装冻结）；重新暂停时固定在当日。`/learn` 顶部「重新开启每日更新」恢复按多伦多日期轮播，任一成员均可操作，首页读取同一设置。仍可主动选日期、收藏和回看；超出通常120天窗口的暂停卡片也保留可读，不改写原日期映射。

开关为家庭共用的 `preferences.learningSchedule`：版本1、`enabled`、`pausedDay`；用既有家庭文档保存并进入JSON备份，不新增SQL或更改个人收藏表。包含在设置聚合，非财务修改不追加财务快照，旧设置操作遇伴侣修改拒绝，未知云端确认／冲突不显示定时任务已生效。个人收藏及`daily`提醒订阅仍独立；暂停后可取消原订阅，重新开启卡片不会替用户订阅消息渠道。已订阅成员在重新启用后从下一次定时检查开始，不补发旧消息；投递已开始则可能完成。

保留 `/api/learning/daily` 的定时检查，服务端仅投影读取该家庭开关，不读取整份财富文档；缺失、无效或关闭时跳过，不发送通知。候选扫描后、认领前再次读取，读取失败停止，不使用旧扫描结果继续发送。无新增模型调用，不改变市场日报、行情、Funda、季度或每周提醒。

本次已独立核对两位白名单成员的唯一共同家庭，将原有1项开启的个人每日提醒改为关闭并回读确认0项启用；保留收藏及其他订阅，不写财富文档。新界面与轮播冻结为本地代码，在部署新版前不声称线上已有按钮或页面已经停止轮播。用户重新开启新版家庭卡片后，如需要外部提醒，需再明确订阅本人每日提醒。

## 版本与管理员

`/updates` 与 `/api/releases` 沿用服务端认证。两个已验证白名单账号均为应用管理员，可看当前包版本、更新内容和已知边界；不提升数据库 service-role 或泄漏环境变量。v0.2.0 与 package.json 一致并有测试约束。此前未逐次编版的历史只汇总为 0.1.0 基线，不捏造发布日期。

## 验证入口

- `npm test`：配置、算术、日期、来源、只读上下文、API 权限、去重和失败路径。
- `E2E_USE_MOCK_AUTH=1 npm run test:e2e`：默认不发通知、不调用真实付费模型。
- `E2E_WEBKIT=1 E2E_USE_MOCK_AUTH=1 npm run test:e2e -- tests/e2e/decision-insights.spec.ts --project=mobile-safari`。
- 线上显式 `RUN_LEARNING_INTEGRATION=1 E2E_BASE_URL=https://sh-wealth.vercel.app npm run test:e2e -- tests/e2e/decision-insights.spec.ts`：临时家庭验证真实个人收藏、伴侣隔离和版本页，结束清理。测试的每日订阅保持关闭。
